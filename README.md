# Поиск по статьям Хабра

Учебный поисковый движок с веб-интерфейсом и API. Основной поиск использует BGE-M3 на MWS и Qdrant. Опечаточник предлагает исправления, которые применяются после нажатия пользователя. Для поиска по словам без MWS есть локальный режим Tantivy.

## Как это работает

Скрапер сохраняет полные статьи в SQLite. Подготовка проверяет тексты, а разбиение создаёт перекрывающиеся фрагменты. BGE-M3 на MWS преобразует их в векторы размерности 1024; Qdrant хранит векторы, тексты и ссылки.

При поиске модель получает только запрос. Qdrant находит близкие фрагменты и возвращает разные статьи. Скачивать и обрабатывать корпус заново не требуется. Интерфейс показывает пять статей, «Показать ещё» раскрывает следующие, до двадцати на запрос.

## Установка и запуск

Нужны Python 3.10+, Docker Compose и ключ MWS. Команды выполняются из папки проекта:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
./run.sh
```

При подготовленных данных скрипт запускает Qdrant и страницу [localhost:8000](http://127.0.0.1:8000). Ключ вводится скрыто в терминале или берётся из `MWS_API_KEY`. Для другого порта добавьте `--port 8001`. Остановка страницы — `Ctrl+C`; Qdrant продолжает работать в фоне.

На другом компьютере сначала перенесите корпус и подготовьте индекс со словарём по [инструкции BGE-M3](docs/BGE_M3.md). Локальные данные и ключи не входят в Git. На текущем компьютере индекс и словарь BGE-M3 уже подготовлены.

Поиск и индексация используют API MWS. Открытие страницы, подсказки и «Показать ещё» модель не вызывают. Если раньше `MWS_EMBEDDINGS_MODEL` указывала на `parser`, уберите это переопределение или установите `bge-m3`.

Поиск из терминала:

```bash
python -m habr_search.retrieval.search --query "Как создавать отчёты Word из Excel?" \
  --qdrant-url http://127.0.0.1:6333
```

## Другие режимы

```bash
# локальный поиск по словам без модели и docker, нужен готовый индекс tantivy
./run.sh --engine tantivy

# экспериментальное объединение tantivy и bge-m3
./run.sh --engine hybrid
```

BGE-M3 выбрана основной по результатам отложенной проверки: у неё и гибрида Hit@5 88,89%, но BGE-M3 показала MRR@5 0,8542 против 0,8148 и медиану 112 мс против 200 мс. Это небольшой контрольный набор, не оценка всего Хабра.

Порог сходства по умолчанию выключен: на dev строгий порог убирает и полезные ответы, а мягкий пока отсеивает только один из четырёх отрицательных запросов. [Проверка порогов и ограничений](docs/evaluation/THRESHOLDS.md).

## Структура

```text
habr_search/
  ingestion/       # сбор, очистка, разбиение и индексация
  retrieval/       # поиск, tantivy, гибрид и опечаточник
  evaluation/      # метрики и сравнение сохранённых отчётов
  web/             # сервер и страница в static/
  model_profiles.py # параметры bge-m3
  embeddings.py    # клиент MWS
  vector_store.py  # подключение к Qdrant
tests/             # автономные проверки
evaluation/        # контрольные запросы
docs/              # инструкции
data/, models/     # локальные данные, исключены из Git
```

## Проверки

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -t . -v
python -m mypy --strict habr_search tests
python -m pyright
```
