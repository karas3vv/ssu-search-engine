# Страница и API поиска

`web.py` запускает локальное приложение FastAPI. Оно использует те же `search_articles`, инструкцию Gemma, токенизатор и коллекцию, что и консольный поиск. Подключения и словарь загружаются один раз, а запросы обслуживаются последовательно. Страница в `static/` работает без Node.js, сборки и внешних шрифтов или скриптов.

## Запуск

Из папки проекта обновите зависимости:

```bash
python -m pip install -r requirements.txt
```

Запустите существующий Qdrant, если он остановлен:

```bash
docker compose up -d qdrant
```

Затем:

```bash
python web.py --qdrant-url http://127.0.0.1:6333 --timeout 300
```

Ключ MWS берётся из `MWS_API_KEY` или один раз вводится скрыто в терминале. Он хранится в памяти процесса, не передаётся странице и не записывается в код, файлы или журналы приложения. Откройте [страницу поиска](http://127.0.0.1:8000). Справочник запросов API доступен по [адресу /docs](http://127.0.0.1:8000/docs). Остановка — `Ctrl+C` в терминале сервера.

Клиент модели создаётся при запуске, но обращение к MWS происходит только при поиске. Открытие страницы, примеры запросов, сведения об индексе и проверка опечаток модель не вызывают. Пример запроса заполняет поле; для поиска нужно нажать «Найти» или Enter. Исправления по умолчанию выключены. «Проверить запрос» показывает предложение локально; нажатие на предложение меняет текст поля, не запускает поиск.

Флажок «Исправлять опечатки» применяет только однозначные замены по правилам `spelling.py`. Страница показывает запрос, реально переданный в поиск. У каждого результата есть заголовок, ссылка на Хабр, фрагмент и косинусное сходство. Сходство не является вероятностью. Показанные при разработке тестовые результаты в рабочий сервер не включены.

## Параметры

- `--port 8001` — другой локальный порт;
- `--spelling-db data/spelling-next.sqlite3` — другой заранее построенный словарь;
- `--without-spelling` — запуск без словаря и исправлений;
- `--tokenizer-file путь/tokenizer.json` — локальный токенизатор Gemma;
- `--max-tokens`, `--overlap-tokens`, `--raw-query` — как в `search.py`, должны соответствовать индексу и настройке сервера модели;
- `--qdrant-path` — встроенный режим вместо сервера; другим командам нельзя открывать эту папку одновременно.

Словарь по умолчанию нужен в `data/spelling.sqlite3`; его можно построить через `spellcheck.py build`. При смене коллекции, текстов или числа фрагментов пересоберите словарь и перезапустите приложение. Сведения на странице — снимок на момент запуска, а не постоянный мониторинг Qdrant.

## API

| Метод и путь | Назначение | MWS |
|---|---|---|
| `GET /api/health` | коллекция, число фрагментов и статей при запуске, наличие словаря | нет |
| `POST /api/suggest` | предложение исправления и варианты | нет |
| `POST /api/search` | семантическая выдача, до 20 разных статей | одно обращение |

Пример тела запроса поиска:

```json
{"query": "автоматизаця документов", "top_k": 5, "correct_typos": false}
```

`POST /api/suggest` принимает только `query`. Запросы должны иметь `Content-Type: application/json`. Неизвестные поля, строки вместо чисел и строковые флаги отклоняются. Пустой запрос или превышение 1024 токенов вместе с инструкцией не отправляются в модель.

Сервер слушает только `127.0.0.1`; это локальный интерфейс без пользовательских аккаунтов. Запросы из браузера с чужим Origin и неизвестным Host отклоняются. Параллельный поиск получает HTTP 429 до обращения в MWS. Ошибка модели возвращает HTTP 502, недоступность Qdrant — 503. Повторов запросов автоматически нет; закрытие вкладки не гарантирует отмену уже отправленного запроса модели.

Жизненный цикл подключения, раздача файлов и HTTP-проверки следуют документации FastAPI: [lifespan](https://fastapi.tiangolo.com/advanced/events/), [static files](https://fastapi.tiangolo.com/tutorial/static-files/), [testing](https://fastapi.tiangolo.com/tutorial/testing/).
